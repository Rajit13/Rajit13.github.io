How this Star Charts map is built

The current StarMaps101.toc supplies section and subsection nodes on every page load. Those nodes are merged with the hand-curated Star Charts 101 topic graph and the IOAA 2025 OM/OT/OP evidence mapping. The graph is then laid out in the browser using Graphology’s ForceAtlas2 implementation in linLogMode.

This keeps the useful division of labour from the previous version: book structure updates automatically, while conceptual claims and IOAA mappings are not invented by automation.
